
# Subscription Tracker

## Project Description

Subscription Tracker is a responsive web application built using ReactJS, HTML, CSS, and JavaScript.

The purpose of this project is to help users manage their subscriptions and keep track of their monthly expenses.

Users can add subscriptions, view their existing subscriptions, delete subscriptions, and automatically calculate their total monthly spending.

The website provides a simple and user-friendly interface that works on both desktop and mobile devices.

## Technologies Used

- ReactJS
- JavaScript
- HTML
- CSS3
- React Router
- Vite
- Git and GitHub
- Vercel

## Website Pages

The application contains five pages:

1. **Home**
   - Introduces the Subscription Tracker website.
   - Explains the purpose of the application.

2. **About Us**
   - Provides information about the website.
   - Explains how Subscription Tracker helps users.

3. **Features**
   - Describes the main features of the application.
   - Explains subscription management and expense tracking.

4. **Contact**
   - Contains a contact form.
   - Includes Name, Email, Phone, Subject, and Message fields.
   - Uses form validation to check user input.

5. **My Subscriptions (Dynamic Page)**
   - Allows users to add subscriptions.
   - Displays subscription names and monthly prices.
   - Allows users to delete subscriptions.
   - Automatically calculates total monthly expenses.

## Main Features

- Add new subscriptions
- View existing subscriptions
- Delete subscriptions
- Calculate total monthly costs automatically
- Contact form with validation
- Responsive design for desktop and mobile
- Navigation between five pages

## Setup Instructions

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/hadirawass44-tech/subscription-tracker.git
```

### 2. Open the Project Folder

```bash
cd subscription-tracker
```

### 3. Install Dependencies

Make sure Node.js and npm are installed.

Run:

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Website

Open the local URL displayed in the terminal.

The default Vite address is:

http://localhost:5173/
